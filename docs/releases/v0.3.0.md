# v0.3.0 — Evidence-Backed Flagship

发布日期：2026-08-20

`v0.3.0` marks the G3 Evidence-Backed Flagship milestone. It adds a controlled,
artifact-backed Agent/RAG comparison to the demo-ready platform and records
the resulting EvalOps release decision.

## Included

- Frozen 20-task manifest, task-independent RAG corpus, fixed model profile
  and three seeds for both baseline and retrieval-enabled candidate arms.
- GitHub Actions formal executor with a protected GLM credential, per-task
  checkpoints and retained raw-suite artifacts.
- Evidence aggregation that validates suite completeness and reconstructs
  tool/retrieval observations from retained task logs when runner-local state
  is unavailable.
- EvalOps aggregate comparison and predeclared gate, plus the versioned G3
  report and machine-readable evidence artifact.

## Result

Across 60 observations per arm, verification pass rate increased from 76.7%
(46/60) to 83.3% (50/60), a +6.7 percentage-point difference. EvalOps returned
`promoted`. This result is bounded by the experiment design and its documented
retrieval-usage limitation; it is not a general benchmark claim.
