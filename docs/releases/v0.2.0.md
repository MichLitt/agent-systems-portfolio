# v0.2.0 — Demo-Ready Product

发布日期：2026-08-12

`v0.2.0` marks the G2 Demo-Ready Product milestone. It turns the published
engineering baseline into a reproducible multi-service demonstration with
durable document ingestion, human review, service authentication and an
evidence-backed runtime check.

## Included

- One-command Compose stack for Agent, RAG API/worker and EvalOps API/worker.
- Persistent volumes, health checks and a deterministic, no-model demo seed.
- SQLite ingestion queue with hash idempotency, lease reclaim, retry and an
  explicit API restart recovery test.
- EvalOps review UI with run inspection, compare/gate evidence and bad-case
  tagging through public APIs only.
- Bearer token protection for business APIs, environment-only secret injection,
  token-aware end-to-end closure and an explicit Agent runtime threat model.

## Verification

```bash
cp .env.example .env

```

by [`artifacts/delivery/demo-readiness.json`](../../artifacts/delivery/demo-readiness.json).

## Limits

This is a single-host demonstration, not a multi-tenant or internet-exposed
deployment. The threat model documents remaining shell, egress, resource-limit
and secret-rotation risks. G3 evidence work remains required before claiming a
measured Agent/RAG quality improvement.
