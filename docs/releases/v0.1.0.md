# v0.1.0 — Release Baseline

发布日期：2026-08-12

`v0.1.0` 是 Agent Systems Portfolio 的工程收敛基线。它将四个独立仓库固定为可复现的统一工作区，并为后续 Demo 与对照实验建立持续验证和交付门槛。

## 范围

- Agent：可恢复的仓库任务执行，接入版本化 EvalOps 事件与 RAG 知识检索。
- RAG：运行时文档摄取、页级溯源与 Agent/RAG 集成报告。
- EvalOps：版本化 producer contract、比较会话与 release gate。
- Finetune：离线 CLI 配置与 smoke 验证；仍为非阻塞的研究扩展。
- 顶层工程：递归 Submodule CI、交付就绪检查、统一 Agent 工程规范与阶段性交付计划。

## 验证

在仓库根目录执行：

```bash
make refresh
make check
python3 scripts/check_delivery_readiness.py --require release
```

发布时的本地验证结果：

- Agent：275 tests passed。
- EvalOps：45 tests passed。
- RAG：415 tests passed，1 项可选模型测试跳过。
- Finetune：5 个核心 CLI smoke passed。
- PDF → RAG ingest → Agent retrieval → Agent/RAG reports → EvalOps compare/gate 的真实 HTTP 闭环通过，Agent 与 RAG gate 均为 `promoted`。

## 已知限制

- 尚未提供统一的容器编排、一键 demo 或 Web review UI。
- RAG ingestion job 仍未实现跨进程持久化和重启恢复。
- 还没有冻结任务集上的 Agent baseline/RAG candidate 对照实验，因此不得主张质量提升数字。
- Finetune 未运行真实训练；README 中的训练结果仍不能视为已验证证据。

这些限制由 [阶段性交付计划](../plans/competitive-portfolio-delivery-plan.md) 中的 G2/G3/G4 工作包覆盖。
